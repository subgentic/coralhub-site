# coralhub-site

The public static pages for coralhub.dev and the subgent.io landing page. Plain HTML, CSS and JavaScript; no build step.

- `coralhub.dev/` the Coral and Coral Hub site (home, downloads, blog, privacy, terms).
- `subgent.io/` the Subgent landing page.

Changes go through pull requests. A merge to `main` publishes the site, so it is merged only when the owner says go.

Coral itself is open source (Apache-2.0): https://github.com/cdknorow/coral
