Common Issues

Open Source

  • Coral is open source (Apache-2.0) with every feature unlocked — no time limit.
  • Every so often when the app opens, Coral shows an activation screen. You can always skip it and keep using the full app.

Installation

  • macOS: Download the DMG from coralhub.dev, drag to Applications, and launch.
  • Linux: Download the tar.gz, extract, and run ./coral --host 127.0.0.1 --port 8420
  • Windows: Download the MSI installer or portable ZIP from coralhub.dev.

Agent Setup

  • Coral works with Claude (Anthropic), Codex (OpenAI), and Gemini (Google, in beta).
  • You'll need to authenticate each agent's CLI separately — Coral uses your existing API credentials.
  • See the documentation for step-by-step setup guides.
